# SmartHostel Admin Panel

Talabalar yotoqxonalari va hostellarni boshqarish, navbatchiliklar hamda talabalar ro'yxatini nazorat qilish uchun Next.js va TailwindCSS yordamida yaratilgan zamonaviy boshqaruv paneli.

## 🚀 Tizim Imkoniyatlari
* **Talabalar Boshqaruvi:** Hostelda istiqomat qiluvchi talabalar va rezidentlarning to'liq ma'lumotlar bazasi.
* **Navbatchilik Jadvali (Duties):** Kunlik navbatchiliklar va hostel ishlarini avtomatik rejalashtirish va taqsimlash.
* **Xonadoshlar Monitoringi (Peers):** Xonalar bo'yicha taqsimot va joylashuvni nazorat qilish.
* **Dashboard & Statistika:** Xonalarning bandlik holati va umumiy ko'rsatkichlar.

## 🛠 Texnik Stack
* **Framework:** Next.js (Pages router), React.
* **Dizayn & Stil:** TailwindCSS, Lucide React (ikonkalar).
* **Dasturlash tili:** TypeScript.
* **Tarmoq So'rovlari:** Axios.
